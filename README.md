## ⚙️ Cách để chạy thử máy mình (nếu bạn muốn xem)

Nếu bạn tò mò không biết một đứa mới học code sẽ viết ra cái gì, có thể clone về máy xem thử nha:

1. **Clone về máy:**
```bash
git clone https://github.com/username/ten-du-an.git

```


2. **Vào thư mục:**
```bash
cd ten-du-an

```


3. **Cài đặt các thứ cần thiết:**
```bash
npm install

```


4. **Bật chế độ xem trước:**
```bash
npm start

```
